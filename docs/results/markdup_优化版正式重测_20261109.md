## 冻结程序与参数

- Markdup 使用上轮最终优化程序，SHA-256 为 `d7c8db1c1d9d41d4e816dcab4adb089314dd8d68f5792d060714b81db5efce1e`。
- Collate、sort、统计验证沿用原正式程序 `81b68788…`；D1/D2 fixmate 也沿用该程序；D3 fixmate 保留原已验证 singleton 修正版 `fc7f37cb…`。完整来源与指纹见各组 `plan.json` / `binaries.sha256`。
- 每条命令六节点，每节点一个 MPI rank / 活跃核组，每 rank 64 CPE；其他核组仅供大共享内存。
- 资源参数保持 `-N 6 -np 1 -health 1 -mpecg 6 -cgsp 64 -share_size 100 -cross_size 88000 -cache_size 32 -xmalloc`。明确选择此前已成功测试的节点；节点限制写入实际提交记录，不写入算法代码。
- Markdup 统一为 `--stream -l 300 -m 8G --compress-level 1`；没有数据集专用算法开关。
- Collate 为 `-n 66`，fixmate 启用 `-m` mate score；BAM 压缩全部 level 1。

| 测试组 | Collate / sort 的 `-m` | RAM pool：collate / fixmate / sort / markdup | 验证 pool |
| --- | --- | --- | --- |
| D1 | 24G / 32G | 8G / 12G / 8G / 8G | 4G |

`-m` 是算法工作集设置，RAM pool 是模拟存储容量，二者不是同一内存预算。外排必须实际选中 external、有非零临时读写、总 runs 大于 rank 数，跟踪工作集不超过原 8 GiB 预算；不接受以 memory 模式替代外排。
