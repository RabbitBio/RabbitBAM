- 原始 BAM：D1 177,798,571 条、D2 365,079,492 条、D3 165,373,770 条。预检核对 SHA-256，与论文冻结输入一致。
- 只读：调用 RabbitBAM 原生 `getBam1_t_parallel` 完整构建 `bam1_t`，再计数。不能使用只扫描记录边界的 `benchmark_count` 替代。
- 读写：同一读取 API 加原生 `write_parallel`，`over_parallel` 完成压缩队列排空和输出关闭；无过滤，BAM 压缩级别 1。

## 线程选优

`nr` 是解压 worker 数，`nw` 是压缩 worker 数，**不等于总线程数**。上游解析和序列化分别使用固定 4 线程，还有读取、预分块、写出等辅助线程。限制 `nr+nw<=120`，为这些工作保留 CPU 空间，不将 120 个 codec workers 误称为 120 总线程。

1. 只读粗筛 `nr=1/2/4/8/12/16/24/32/48/64/96/120`。
2. 读写粗筛 codec worker 总数 `16/32/64/96/120`，在每个总数下测试约 `1:4`、`1:2`、`1:1` 的读写分配；补充若干 `2:1` 配置。
3. 对粗筛赢家做线程数邻域细筛。
4. 最快三个配置各交错跑三次，顺序为正序、反序、正序。以确认阶段 wall 中位数选出该数据集、该模式的最佳已测配置。
5. 最佳配置再独立正式跑三次，报告中位数和 min--max 范围。不能从单次粗筛选一个偶然最快值当正式成绩。

搜索不声称覆盖一切可能配置或证明全局最优；目标是在原生实现和可用 128 核内合理充分选优。不同数据集、不同模式分别选参。
