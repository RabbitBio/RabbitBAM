# D3 Samtools 库基准结果

## 1. 测试概述

在 A4 x86 服务器上使用 Samtools 对 D3 执行只读扫描和 BAM read-write
回环，用于评估大规模 WGS 数据下的性能与线程扩展性。测试均直接读写
`/home/bigssd` NVMe，表中时间为包含文件 I/O 的端到端 wall time。

| 项目 | 配置 |
|---|---|
| 日期 | 2026-09-25 至 2026-09-26 |
| 主机 | `a4.localdomain` |
| CPU | 2 x AMD EPYC 7T83，128 个在线物理核 |
| 内存 | 251 GiB |
| Samtools / HTSlib | 1.20 / 1.20 |
| 压缩库 | libdeflate 1.20 |
| 文件系统 | `/home/bigssd`，7.0 TiB NVMe，ext4 |
| 输入 | `D3-WGS-85G.coordinate.bam` |
| 输入大小 | 89,994,058,306 bytes（9.994 GB） |
| 记录数 | 1,210,633,370 |
| Read-write 输出大小 | 99,004,322,202 bytes（99.004 GB） |

D3 从 fat 通过内网传输到 A4，传输耗时 `268.64 s`，不计入下述基准。
输入在测试前通过 `samtools quickcheck`。

## 2. 测试方法

测试线程点为 `0/2/4/8/16/24/32/47/48/64/96/127`，每个点运行 3 次。
三轮顺序为升序、降序、升序，表中使用中位数。测试未主动清理 Linux
page cache。`-@` 表示 Samtools/HTSlib 的附加解压或压缩线程数。

只读命令：

```bash
/usr/bin/time -o read.log \
  -f 'wall_s=%e user_s=%U sys_s=%S cpu=%P maxrss_kb=%M fs_inputs=%I fs_outputs=%O exit=%x' \
  /home/user_home/wzs/software/samtools-1.20/bin/samtools \
  view --no-PG -@ "$threads" -c \
  /home/bigssd/wzs_data/D3-WGS-85G/initial/D3-WGS-85G.coordinate.bam
```

Read-write 命令：

```bash
/usr/bin/time -o rw.log \
  -f 'wall_s=%e user_s=%U sys_s=%S cpu=%P maxrss_kb=%M fs_inputs=%I fs_outputs=%O exit=%x' \
  /home/user_home/wzs/software/samtools-1.20/bin/samtools \
  view --no-PG -@ "$threads" -O BAM,level=1 \
  -o D3.roundtrip.bam \
  /home/bigssd/wzs_data/D3-WGS-85G/initial/D3-WGS-85G.coordinate.bam

/home/user_home/wzs/software/samtools-1.20/bin/samtools \
  quickcheck -v D3.roundtrip.bam
```

每次 read-write 完成后立即执行 `quickcheck` 和文件大小核对，然后删除
临时输出，任一次失败都会终止后续测试。
