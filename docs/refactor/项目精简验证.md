## io-check 新实现

```text
memory / POSIX / MPI-IO input + input plan
    -> RunRecordCountPipeline -> BAM read -> CPE decode/parse/count

synthetic block source -> RunBgzfCompressPipeline -> BAM write -> CRC/payload verify

memory input -> RunBamTransformPipeline (passthrough / MAPQ>=30)
    -> BAM read -> pack -> BAM write -> RankBodySink
    -> header/body/EOF -> independent MPE decode verification
```

保留后端 header/size/span 一致性检查、合成块逐字节校验、CRC/ISIZE、record 边界、
回环记录数与字节数、过滤保留数及过滤后每条记录的 MAPQ 检查。预期计数由独立主核
解压扫描生成，不仅依赖待测算子自报统计。新增/重写诊断本身不属于算法性能路径。
